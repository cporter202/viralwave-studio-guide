# The Prompt Library: 25+ Copy-Paste AI Prompts

These prompts turn one pillar + a few business details into finished post drafts. Replace the `[BRACKETED]` parts with your info, paste into any AI chat tool, and edit the output in your voice.

**Golden rules:**
- Always give the AI your business context first (the "context block" below) — generic prompts get generic posts.
- Generate 3–5 variations per slot, pick the best, edit lightly. Editing beats regenerating.
- Save your winners. Your best-performing posts become examples in future prompts ("write more like this: [paste]").

## The context block (use with every prompt)

Paste this before any prompt below, filled in for your business:

```
Business: [name, what you sell, city if local]
Audience: [who buys from you, in plain words]
Voice: [3 adjectives, e.g. "warm, direct, funny" — plus one "never" e.g. "never corporate-speak"]
Offer: [current offer or "none this month"]
```

## Ideation prompts

### 1. Month of ideas from one pillar
```
Using the context above, give me 10 post ideas for the [PILLAR] pillar.
Each idea: a hook (under 12 words), one-sentence angle, and suggested format
(video / carousel / single image / text). Avoid ideas I've likely seen before —
no generic motivational quotes.
```

### 2. Fill my calendar gaps
```
My content pillars are [LIST]. I've already covered these topics this month:
[LIST]. Give me 8 fresh post ideas that avoid overlap, weighted toward
[TEACH/SHOW] pillars. Include a hook for each.
```

### 3. Steal like an artist (trend remix)
```
Here are 3 posts going viral in my niche right now: [PASTE OR DESCRIBE].
Break down WHY each one works (hook structure, emotion, format), then give me
3 original post ideas for my business using the same mechanics — not copies,
not the same topic.
```

## Hook prompts

### 4. Hook machine
```
Write 15 opening hooks for a post about [TOPIC]. Mix these styles: bold claim,
curiosity gap, contrarian take, specific number, relatable pain. Under 12 words
each. No clickbait that the post can't deliver on.
```

### 5. First-3-seconds video hook
```
Write 10 spoken opening lines (under 5 seconds each) for a short-form video
about [TOPIC]. They must work with the sound off as on-screen text too.
Conversational, not salesy.
```

## Caption & post prompts

### 6. Full caption draft
```
Write a [PLATFORM] caption about [TOPIC] for the [PILLAR] pillar.
Structure: hook, 2-3 short paragraphs or line breaks, one clear CTA
([comment / DM / link / save]). [LENGTH: short/medium]. Match my voice.
End with 5-8 relevant hashtags (or "no hashtags" for LinkedIn/X style).
```

### 7. Carousel outline
```
Outline a [5-7] slide carousel about [TOPIC]. Slide 1: hook. Slides 2-[n-1]:
one idea per slide, under 25 words each. Last slide: CTA ([follow/save/DM]).
Give me the text for each slide plus a one-line visual direction.
```

### 8. Story post (Human pillar)
```
Help me turn this experience into a post: [DESCRIBE WHAT HAPPENED, 3-4 sentences].
Structure: the moment, what I realized, what it means for my customers.
Honest and specific — no invented details, no generic "grateful" filler.
Under 200 words.
```

### 9. Offer post (Sell pillar)
```
Write a [PLATFORM] post for this offer: [OFFER DETAILS, price, deadline].
Lead with the outcome for the buyer, not the features. Include genuine urgency
(deadline or limited spots — don't invent scarcity). One CTA. Under 120 words.
```

### 10. Testimonial post (Prove pillar)
```
Turn this customer feedback into a post: "[PASTE REVIEW]".
Don't just quote it — add one line of context about the customer's starting
point, the quote itself, and one line on what made it work. CTA: invite readers
to imagine their own version.
```

## Video script prompts

### 11. 30-second talking-head script
```
Write a 30-second talking-head video script about [TOPIC].
Format: HOOK (0-3s, spoken + on-screen text) / BODY (3-25s, 3 beats max) /
CTA (25-30s, one action). Write it how people actually talk — contractions,
short sentences. Include 2 B-roll suggestions.
```

### 12. B-roll + text overlay video
```
I film [DESCRIBE YOUR WORK/PROCESS]. Give me 5 video concepts that are just
B-roll footage with text overlays — no talking. For each: what to film
(3 shots), the exact on-screen text, and the caption.
```

### 13. Day-in-the-life outline
```
Outline a 45-60 second "day in the life of a [YOUR ROLE]" video.
8-10 timestamped beats, each with what to film and a one-line voiceover or
caption. Make the mundane interesting — find the moments customers are
curious about.
```

## Repurposing prompts (one post → five)

### 14. The content multiplier
```
Here's a post that performed well: [PASTE IT].
Repurpose it into: (1) a 5-slide carousel outline, (2) a 30-second video script,
(3) a Threads/X post under 280 characters, (4) an email paragraph,
(5) a Pinterest pin title + description. Keep the core idea, change the packaging.
```

### 15. Blog post → social week
```
Here's my blog post: [PASTE URL OR TEXT]. Extract 5 standalone social posts
from it — each must make sense without reading the article. Mix: 2 tips,
1 story/behind-the-scenes, 1 contrarian take, 1 question post. Include hooks.
```

### 16. Review → post (ongoing engine)
```
I get customer reviews regularly. Build me a reusable system: a prompt I can
paste any future review into that outputs a finished Prove-pillar post in my
voice, with the review woven in (not just quoted) and a soft CTA.
```

## Engagement prompts

### 17. Question posts
```
Give me 10 question-style posts for [AUDIENCE] about [TOPIC AREA].
Questions people actually want to answer (opinions, experiences, this-or-that) —
not quiz questions, not engagement bait. One line each.
```

### 18. Comment reply starter kit
```
Write 12 short, warm reply templates for common comments on my posts:
compliments, questions about price, skepticism, off-topic, spam-adjacent.
Sound like a human, not a brand account. Leave [brackets] where I personalize.
```

## Seasonal & timely prompts

### 19. Holiday content calendar
```
List the holidays, seasons, and awareness days in [MONTH(S)] relevant to
[AUDIENCE/BUSINESS TYPE]. For the 5 most relevant, give me one post idea each
tied to my pillars — genuine connection to the day, not forced.
```

### 20. Newsjack (carefully)
```
This is trending in my industry: [DESCRIBE]. Give me 3 ways to post about it
that add my perspective — not just resharing the news. Include one "what this
means for you" angle for my customers and one thing to avoid saying.
```

## Blog & SEO prompts

### 21. SEO blog outline
```
Outline a 1,200-word blog post targeting the keyword "[KEYWORD]".
H2s that answer real search intent, FAQ section with 4 questions, meta title
(under 60 chars) and meta description (under 160). Written for humans first.
```

### 22. Blog draft from outline
```
Expand this outline into a full draft: [PASTE OUTLINE]. Conversational expert
tone, short paragraphs, one concrete example per section. No fluff intros —
start with the answer.
```

## Image & visual prompts

### 23. AI image prompt builder
```
I need a [PLATFORM] image for a post about [TOPIC] in the [PILLAR] pillar.
Write me a detailed AI image-generation prompt: subject, composition, lighting,
color palette matching [BRAND COLORS / vibe], style (photorealistic/illustrated),
and what to avoid (text in image, extra fingers, brand logos). Square format.
```

### 24. Carousel visual direction
```
For this carousel outline: [PASTE OUTLINE]. Give me a visual system:
background style, text placement, one accent color usage rule, and a
cover-slide concept that stops the scroll. Consistent across all slides,
readable on a phone screen.
```

## The monthly batch prompt (the big one)

### 25. Full month generation
```
Using my context block and pillars [LIST], generate a 30-day content plan:
one post per day following this rotation [YOUR ROTATION]. For EACH day give me:
pillar, hook, format, and a 2-sentence content brief (not the full post — the
brief). Flag the 4 Sell-pillar days. Avoid repeating topics. Output as a
numbered list I can work through in a batch session.
```

Then take each brief through prompts 6–13 to write the full posts. The briefs keep you fast; the individual prompts keep quality high.
